# claude-chan

Виртуальное воплощение Claude: пиксельная девочка, которая живёт на рабочем столе, ходит по нему,
меняет позы, говорит облачком над головой и помогает управлять ПК и работать.

> Статус: **прототип, отложен «на дальнюю полку»**. Работает основа (окно, мост к Claude, спрайты),
> последние правки интерфейса собраны, но не проверены на экране. См. [«Что дальше»](#что-дальше).

## Идея

Не окно чата, а персонаж. Она:

- **живёт на рабочем столе:** ходит вдоль нижнего края экрана, стоит, меняет позы, сама что-то говорит;
- **общается облачком** над головой, как в игре. Клик по ней открывает поле ввода прямо в облачке;
- **управляет ПК** через Claude Code: запускает программы, ищет файлы, регулирует звук и медиа,
  показывает уведомления, работает с кодом и проектами; почта и календарь появятся, если подключить
  соответствующие MCP-коннекторы в своём Claude;
- **показывает, что делает:** думает, ходит с ноутбуком, пока работает, радуется, а если что-то сломалось,
  появляется в саже с гаечным ключом.

Референс по ощущению: видео в TikTok [@thatlev](https://www.tiktok.com/@thatlev/video/7698054601727118625)
(десктопный питомец, который ходит по столу, меняет позы и говорит облачком; видео я посмотреть не смог,
описание со слов автора идеи).

Внешность придумана автором идеи: рыжие кудри (распущенные или хвост), очки, белый топ с бантиком,
чёрные шорты, белые чулки, ноутбук ThinkPad. Картинки сгенерированы нейросетью и лежат в `chan-img/`.

## Как это устроено

```
  ┌────────────── Electron ──────────────┐
  │ main.ts      окно, ходьба, IPC       │        claude -p --output-format stream-json
  │ claude.ts  ──────────────────────────┼──────▶  (Claude Code CLI, сессия сохраняется)
  │ renderer.ts  спрайты, облачко, жизнь │◀────── текст потоком, вызовы инструментов
  └──────────────────────────────────────┘
```

- **Мозг:** Claude Code CLI в headless-режиме (`src/claude.ts`). Он ведёт сессию между сообщениями
  (`--resume`), сам вызывает инструменты. Персона задана через `--append-system-prompt`; в начале каждого
  ответа Claude ставит тег настроения `[mood:happy]`, `[mood:sad]` и т. д., а интерфейс вырезает его и
  меняет позу.
- **Окно** (`src/main.ts`): прозрачное, без рамки, поверх всех окон. Само окно (440×720) двигается по
  экрану: разгон и торможение, возврат на «пол» после перетаскивания. Пустые места пропускают клики на
  рабочий стол (`setIgnoreMouseEvents` с `forward`), поверх неё и облачка ввод включается.
- **Интерфейс** (`src/renderer/`): спрайты, пиксельное облачко с печатью по буквам, шаговая анимация,
  собственная «жизнь» в простое (прогулки, смена поз, реплики, напоминания).
- **Запуск через XWayland** (`--ozone-platform=x11`): на GNOME/Wayland иначе не работают прозрачность и
  «поверх всех окон».

### Позы и состояния

| Спрайт | Когда |
|---|---|
| `idle` | ждёт, рука на бедре |
| `think` | запрос отправлен, ответа ещё нет |
| `walk1`/`walk2` | идёт или работает (два кадра ходьбы с ноутбуком) |
| `happy` | радуется или удивлена (машет рукой) |
| `fix_tail` | ошибка или «грустно» (в саже, с гаечным ключом) |
| `*_tail` | вариант с хвостом (`"hair": "ponytail"` в конфиге) |
| `tpose` | не используется, заготовка для рига |

### Характер

`src/renderer/phrases.ts`: приветствия по времени суток, реплики на клик и на наведение,
случайные замечания, напоминание размяться (раз в 50 минут), ночное «пора спать».
Это обычный список строк, править можно прямо там.

## Запуск

Нужны Node.js 20+ и установленный и залогиненный [Claude Code](https://claude.com/claude-code) (`claude` в PATH).

```bash
npm install
npm start      # сборка + запуск
```

На других системах флаги запуска в `package.json` (`--ozone-platform=x11 --enable-transparent-visuals --disable-gpu`)
возможно придётся поменять.

- Клик по ней: открыть или закрыть поле ввода. Перетаскивание: двигает её. Правый клик: меню.
- `Esc` закрывает поле ввода, `■` в облачке прерывает работу.

## Настройки

Файл создаётся при первом запуске: `~/.config/claude-chan/config.json`.

| Поле | Значение |
|---|---|
| `workspace` | папка, в которой работает Claude (по умолчанию домашняя) |
| `allowedTools` | что можно без вопросов; в headless-режиме спросить подтверждение нельзя |
| `fullAccess` | `true`: полный доступ без проверок. **Включать осознанно** |
| `hair` | `"loose"` или `"ponytail"` |
| `clickThrough` | `false`, если окно блокирует клики там, где её нет |
| `model` | необязательно, модель Claude |

По умолчанию она работает в безопасном режиме: читает файлы, ищет, ищет в сети и запускает только
`wpctl`, `playerctl`, `notify-send`, `xdg-open`, `ls`, `date`, `gdbus call`. Всё остальное отклоняется,
и она об этом скажет.

## Спрайты

Исходники лежат в `chan-img/*.jpg` (белый фон). `scripts/prepare_sprites.py` вырезает фон, убирает подпись
кадров, выравнивает все кадры по тени под ногами, делает тень полупрозрачной и пишет PNG в
`src/renderer/sprites/`:

```bash
python3 -I scripts/prepare_sprites.py   # нужен Pillow, ~25 секунд
```

В `assets/` лежит ранняя версия, нарисованная в GIMP через MCP (`claude-chan.xcf` со слоями и PNG).
Она не используется в приложении, но слои глаз и рта можно взять для анимации.

## Что дальше

Это то, что было задумано, но не сделано или не проверено.

1. **Проверить на экране последние правки:** шрифт Ark Pixel, пиксельное облачко и его хвост, реплики,
   разгон и торможение. Проверка прервалась на скриншотах. Идея: запустить настоящее приложение, а
   `webContents.capturePage()` сохранить в PNG (в проект такой скрипт не вошёл).
2. **Плавная анимация.** Главное, чего не хватает: из статичных поз и двух кадров ходьбы живости не
   получить, движение «скользит». Нужны новые кадры в том же стиле (тот же холст и положение, белый фон):
   полный цикл ходьбы (6–8 кадров) вправо и влево, поворот, сидит, спит, потягивается, говорит (открытый
   и закрытый рот), моргание. Дальше `prepare_sprites.py` их подхватит.
3. **Звук:** шаги, «говорилка» при печати, уведомления.
4. **Больше самостоятельности:** реакции на то, что происходит на экране, сидение на краях окон, сон ночью.
5. **Голос:** озвучка и голосовой ввод (сейчас только текст).

## Известные ограничения

- Ходит только вдоль нижнего края основного монитора, окна не использует.
- В кадрах ходьбы у неё всегда ноутбук; ходьба есть только с распущенными волосами, поза с ключом только с хвостом.
- Белые вкрапления в завитках волос оставлены намеренно: это нарисованные блики.
- Рот не двигается: в исходных картинках его нет.
- Клик сквозь прозрачные части окна на XWayland не проверен, запасной вариант: `"clickThrough": false`.

## Что ставится на машину

Ничего системного. Проект целиком живёт в своей папке (`node_modules` ≈ 300 МБ, не в git) плюс кэши:
`~/.cache/electron` (≈ 100 МБ) и `~/.config/claude-chan` (настройки и кэш Chromium). Для обработки спрайтов
нужен Python с Pillow. Полностью убрать: удалить `node_modules`, `dist`, `~/.cache/electron`,
`~/.config/claude-chan`; вернуть: `npm install`.
